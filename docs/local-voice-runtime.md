# Local Kokoro voice runtime

The reader can generate narration in the browser with Kokoro-82M on ONNX Runtime Web. The worker uses CPU WASM with one inference thread, keeps one model instance, serializes requests, and returns 24 kHz `Float32Array` audio. It accepts the complete text passed by the reader. Long passages are split at sentence or whitespace boundaries and checked after splitting so every source character is retained. The worker keeps at most two recent audio results in memory; it does not persist reading text or audio.

The worker entry point is `web/local-voice-worker.js`. Send `{ id, type: 'generate', text, voice }`, where `voice` is `af_heart`, `am_michael`, or `bm_george`. It replies with `{ id, type: 'audio', samples, sampleRate: 24000 }`, transferring the sample buffer. Model-load progress uses `{ id, type: 'progress', message, loaded, total }` when byte counts are available; generation progress supplies a message without byte counts. Optional `{ id, type: 'prepare' }` warms the model and replies `{ id, type: 'ready' }`. Requests run one at a time. Terminate the worker to stop active inference.

The patched Kokoro/Transformers bundle, ONNX WASM pair, and three small voice bins are in `web/vendor/kokoro/`. WASM and voice files are served from the same origin. Phonemizer is externalized: the browser imports `phonemizer@1.2.1` from the exact jsDelivr npm CDN URL below. The self-hosted runtime does not contain its eSpeak NG payload; natural voice phonemization therefore needs that third-party CDN at runtime. The model weights remain at the public model repository because the q8 ONNX file is about 92.4 MB; the browser downloads that file from the immutable revision below and the Transformers.js cache may retain it for later use. There is no paid inference service, API key, or account requirement. The site does not guarantee free or uninterrupted third-party hosting; either public host can change availability or limits.

## Pinned inputs

- Kokoro source: [`hexgrad/kokoro` commit `664c76a704021239ba59c84dcbaa4d3dece01fe9`](https://github.com/hexgrad/kokoro/tree/664c76a704021239ba59c84dcbaa4d3dece01fe9), the source commit published for [`kokoro-js` 1.2.1](https://www.npmjs.com/package/kokoro-js/v/1.2.1). The runtime build pins model revision `1939ad2a8e416c0acfeecc08a694d14ef25f2231` and patches the voice loader to same-origin files.
- Transformers.js: 3.5.1, resolved by Kokoro's pinned `package-lock.json` and bundled into the browser runtime with esbuild 0.25.2. The build runs `npm ci --ignore-scripts --no-audit --no-fund` in a fresh retained temporary directory.
- External phonemizer: [`phonemizer` 1.2.1](https://www.npmjs.com/package/phonemizer/v/1.2.1), loaded from [`https://cdn.jsdelivr.net/npm/phonemizer@1.2.1/+esm`](https://cdn.jsdelivr.net/npm/phonemizer@1.2.1/+esm). It is not embedded in the local runtime bundle. The package source is [`xenova/phonemizer.js` commit `6835144b7ee9043129222549c1ed2f6a27216278`](https://github.com/xenova/phonemizer.js/tree/6835144b7ee9043129222549c1ed2f6a27216278).
- ONNX runtime assets: [`onnxruntime-web` 1.22.0-dev.20250409-89f8206ba4](https://www.npmjs.com/package/onnxruntime-web/v/1.22.0-dev.20250409-89f8206ba4). Keep the `.mjs` loader and `.wasm` binary from this same package version.
- Model and voice data: [`onnx-community/Kokoro-82M-v1.0-ONNX`](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX/tree/1939ad2a8e416c0acfeecc08a694d14ef25f2231), revision `1939ad2a8e416c0acfeecc08a694d14ef25f2231`. The model weights are fetched at this revision; the selected voice bins are vendored locally from it.
- Phonemizer source snapshot: [`xenova/phonemizer.js` commit `6835144b7ee9043129222549c1ed2f6a27216278`](https://github.com/xenova/phonemizer.js/tree/6835144b7ee9043129222549c1ed2f6a27216278), also available as [this source archive](https://github.com/xenova/phonemizer.js/archive/6835144b7ee9043129222549c1ed2f6a27216278.tar.gz).

`web/vendor/kokoro/provenance.json` records artifact sizes and SHA-256 values, the source and package pins, and reproducible build details. Rebuild the runtime and voice files with `node scripts/vendor-local-voice.mjs` (Node.js 18+, npm, and `tar` required). The script verifies the Kokoro source archive SHA-256, installs its lockfile dependencies with lifecycle scripts disabled, verifies the ONNX Runtime package integrity and voice-file SHA-256 values, and retains its temporary build tree for inspection. It does not download the 92.4 MB model file.

## Licenses and source status

Full license texts are included in `web/vendor/kokoro/licenses/`; component attribution and pinned source links are in `web/vendor/kokoro/THIRD_PARTY_NOTICES.md`. Kokoro, Transformers.js, Phonemizer.js, the model and voice files use Apache-2.0; ONNX Runtime components use MIT; the eSpeak NG payload served by the external Phonemizer package is GPL-3.0; ONNX Runtime's listed transitive components also include BSD-3-Clause and ISC licenses. The repo's runtime does not bundle that payload, but the browser still requests it from jsDelivr.

Externalizing Phonemizer removes the unknown eSpeak NG binary from this repository's self-hosted runtime; it does not establish license clearance for the separate CDN package or any downstream redistribution. The published Phonemizer.js source snapshot contains its Emscripten worker output and phoneme data, but does not identify the original eSpeak NG C-source revision or include its C sources and build inputs. The full GPL-3.0 text and exact Phonemizer.js source link are included, but they do not establish corresponding-source compliance for the CDN-served eSpeak NG build. Keep that source/provenance status unresolved unless exact upstream source/build materials are obtained or a phonemizer without the gap is selected.
