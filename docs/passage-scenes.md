# Passage-specific Journey scenes

This register describes the authored verse coverage in `data/journey/passage-scenes.json`. It is content documentation, not a record of browser acceptance. Outside these ranges the reader uses its existing story world, object study, or clearly labeled broad book context.

Hotspots identify actual visible people, actions, or objects. Scripture stays verbatim in its own view; the Context view contains the illustrations and editorial notes. A subject inspection preserves the saved verse and audio target; the explicit Read link changes the passage.
